SDX2 — Command Reference

Every command, hotkey, and tip you need to play on SDX. Click any command to copy it.

⚠
All commands are case-sensitive — both the command itself and any argument (ship name, player name, faction tag). If a name contains a space, put it in quotes: !fixship "My Ship Name".
